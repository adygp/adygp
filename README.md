# Dashboard Literasi & Survei Lingkungan Belajar

Aplikasi dashboard analitik literasi, numerasi, observasi pembelajaran, dan survei lingkungan belajar (SURLINGJAR).

## Fitur
- Analisis data literasi & numerasi
- Visualisasi grafik interaktif
- Ekspor PDF, Excel, dan CSV
- Dukungan Netlify & static deployment
